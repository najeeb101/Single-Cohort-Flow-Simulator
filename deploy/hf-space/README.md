# CS Intake Planner (live demo)

A read-only demo of the decision tool built for Qatar University's CS department: a discrete-term,
agent-based simulation of every student moving through the real 2024 CS study plan, used to answer
"how many students should we admit next intake, and what course seats does that number need?"

The numbers here are **illustrative** (partly estimated inputs). Source code and method:
https://github.com/najeeb101/Single-Cohort-Flow-Simulator
